# バグの種類の分布と、バグの特定の精度（2026-11-14）

課題の Option B が最初に求める「報告されたバグの種類・特性」を示すための集計（RQ1 の前半）。`scripts/22_bug_type_distribution.py`。

## 対象

- ゲーム本体と分類した 181 プロジェクトの、バグのラベルが付いた Issue（修正なしのラベルを除く）：**49,381 件**。
- このうち、修正の最終差分までたどれて本分析に使ったもの：**10,082 件（20.4%）**。残りは、リンクされた PR がない（34,893 件）、PR がマージされていない、コミットがデータにない、など。

## 症状の分布（キーワード規則による。評価用での正解率 0.71、κ 0.59）

| 症状 | ゲームのバグ全体（49,381） | 本分析の対象（10,082） | 修正までたどれないもの（39,299） | 修正までたどれる割合 |
|---|---:|---:|---:|---:|
| ルール・状態 | 45.9% | 45.8% | 45.9% | 20.4% |
| UI | 22.8% | 24.7% | 22.3% | 22.2% |
| クラッシュ・停止 | 10.7% | 9.9% | 11.0% | 18.8% |
| 描画 | 8.6% | 7.8% | 8.8% | 18.5% |
| ツール（ビルド・エディタなど） | 5.3% | 5.2% | 5.3% | 20.2% |
| 音声 | 2.4% | 2.6% | 2.4% | 21.8% |
| ネットワーク | 2.2% | 2.1% | 2.2% | 20.0% |
| 性能 | 1.4% | 0.9% | 1.5% | 13.5% |
| セーブ・ロード | 0.8% | 0.9% | 0.7% | 25.4% |

- **ゲームのバグの約半分はルール・状態の不具合で、UI が約 4 分の 1**。クラッシュと描画がそれぞれ 1 割前後、音声・ネットワーク・性能・セーブは合わせて 1 割未満。
- **修正までたどれるバグ（本分析の対象）と、たどれないバグとで、症状の割合はほぼ同じ**（差は最大 2.4 ポイント、UI）。修正までたどれる割合も、症状によって 13〜25% と大きくは変わらない。
  → 本分析を修正までたどれるバグに限ったことで、症状の構成が大きく偏ったわけではない。ただし、PR を使う習慣のあるプロジェクトへの偏りは残る。
- 「ルール・状態」は、どの規則にも当たらなかったものも含む。なので、実際のルールのバグよりやや多めに出ている可能性がある（評価用で、描画の見落としが多かった）。

## バグの特定（ラベルの規則）の精度

試行用 100 件（ゲーム本体のバグ。Codex による判定）で、ラベルで選んだ Issue が本当にバグかを確かめた。
- バグ：97 件
- バグではない（機能の要望など）：1 件
- 判断できない：2 件

ラベルによるバグの特定は、ほぼ正しい（97%）。評価用 100 件の判定は、本人の 50 件が終わるまで封印している。開けたら、人の判定でも確かめる。
