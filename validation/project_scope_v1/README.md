# プロジェクト範囲の暫定判定

2026-11-12、Codexが収録READMEの目的説明を読み、必要な追加箇所を確認して判定した。人の独立検証前。
`decisions.json` と `review_additions.json` が判定データ、`labels.jsonl` がプロジェクトキー・短い根拠・出典を含む展開版。
インデックスは `results/cohort_v1/scope_review_cards.jsonl` の固定した順序に対応する。
キーワードによる候補行の取り出しは表示補助であり、それだけでラベルを推論したものではない。

- game：特定ゲーム、そのゲームの規則を実装するオンラインサービス、既存ゲームの移植・再実装、完全なゲームモード。
  原版の素材が別途必要であることだけでは除外しない。
- engine_tool：汎用エンジン、ライブラリ、開発・運用・攻略支援、ランチャー、エミュレータ、ゲームを実行しない補助ソフトや資料。
- mixed：ゲームとツールの混在、部分MOD、単独ではゲーム全体と認定しにくい専用部品等。主分析候補から保留。
- unknown：確認した情報だけでは主な成果物が分からない。名前だけでgameへ補完しない。

判定結果はgame 181、engine_tool 125、mixed 20、unknown 22。
VCMI・SS3D・HattrickOrganizerは現行公開ページの情報を補足に使い、収録README由来の根拠とは分けた。
移植・エンジン再実装・MOD・専用サーバー等の境界には裁量があり、個別判定と感度分析が必要。
各ラベルはmedium/lowの暫定判定として保存している。根拠引用の正しさを機械的に検査しているが、意味の妥当性を証明したものではない。

主分析の最終差分の定義が未確定のため、ここから得た10,511件・約7.0%を最終結果として引用しない。
