## 5. 分かったこと

- 規則は、テスト関連のファイルをおおむね正しく拾っている（適合率 92%、既知の見落とし 0.5%）。
- ただし「テスト関連のファイルの変更」の約 4 分の 1 は、テストデータやモックだけの変更。「テストのコードを書いた」より広い指標であることを、レポートで明記する。
